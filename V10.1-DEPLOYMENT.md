# RABBIT V10.1 · deployment notes

## Implemented in GitHub Pages
- Original V9 welcome and interest onboarding retained. Navigation is gated until curiosity experience.
- Curiosity feed: locally weighted engagement ranking, broad random discovery, editorial motion.
- Warren: Explore/search, bookmarks, local profile photo grid and multi-photo posts.
- Clubs: local editable custom club cover URLs (new clubs), channel sidebar, polls and challenges.
- Explore: Open Library work descriptions (when available), personal local book notes, mood discovery.
- Account: Supabase email signup/signin page.
- Live Community: `community.html` for shared Warren posts/comments, club creation/join, channel messages, reader profiles.

## What is NOT yet deployed
GitHub Pages cannot apply database migrations. The live community remains gated until the owner runs `sql/rabbit_v10_social.sql` in their own Supabase SQL Editor and verifies policies, auth redirect URLs, and email settings. The app detects missing tables and shows a status message. No service-role keys should ever be placed in browser files.

Before opening to the public: deploy and review RLS, add spam/rate limiting, abuse reporting/moderation, privacy settings, image upload storage policies, and test with two distinct accounts. Club polls and photos remain device-local demos; Live Community supports text posts/chat only. Browser-local likes and interests do not sync to accounts. Supabase realtime subscription is not wired; use Refresh for updates.

## Test checklist
1. On welcome screen and interest selection, **no** navigation/For You/Warren shortcut should show.
2. Enter curiosity feed; nav and For You appear.
3. Select interests once; reload and confirm stored preferences, and navigate back through welcome as designed.
4. Follow/read/like a book; verify taste is stored in `rabbit_taste_v101` and the feed stays mixed.
5. Test Warren search, bookmarks, profile, multi-photo posts and local storage.
6. Create a club; customize cover; create and vote in a poll; test channels.
7. Explore Open Library books; verify description loading/failure states and local notes.
8. After SQL deployment, test two accounts sharing a post, comment, membership and channel message.
