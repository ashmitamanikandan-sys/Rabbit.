
# RABBIT Book Importer

This folder contains scripts for building RABBIT's book library.

Our importer will:
- Fetch real book metadata from Open Library.
- Collect titles, authors, genres, and available covers.
- Avoid duplicate books and editions.
- Keep incomplete books out of the public feed.
- Import books into Supabase in manageable batches.

Our long-term goal is a library of millions of books.
